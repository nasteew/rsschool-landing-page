# rsschool-landing-page

Two-page landing for **AURA Beauty Studio** (hair, nails, skin, makeup).

**Variant:** author project (not a Figma template).

## Pages

- `index.html` — home
- `catalog.html` — services and prices

Stack: HTML, CSS, vanilla JavaScript modules. No CSS/JS frameworks.

## Theme

The theme toggle stores `light` or `dark` in `localStorage` (`aura-theme`).
